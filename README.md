# The Infinite Fitting Room Analysis | E-Commerce Reverse Logistics

## Executive Summary
Architected a comprehensive e-commerce reverse logistics model in Advanced Excel to investigate product return drivers, evaluate brand-level margin erosion, and isolate profit leaks across apparel categories.

## Key Outcomes & Business Impact
* **Return Baseline:** Isolated a **28.9% product return rate** across core apparel categories[cite: 20].
* **Profit Leak Identification:** Pinpointed sizing issues as the **#1 driver of returns (38%)**, contributing to significant margin loss in reverse shipping and restocking fees[cite: 20].
* **Brand Insights:** Evaluated outer-wear category performance and brand-wise overhead costs across H&M, Zara, Gap, and Banana Republic[cite: 20].

* **Tooling:** Microsoft Excel (Advanced Modeling)
* **Data Transformation:** Dynamic Array Formulas, Conditional Formatting, XLOOKUP
